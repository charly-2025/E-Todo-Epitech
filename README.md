# E-Todo Project

E-Todo is a web application for managing your to-do tasks efficiently. You can create, update, and track your tasks, all in one place, with a calendar view to visualize deadlines.

## Features
- Create To-Dos: Add tasks with a title, description, and custom deadline.
- Update Status: Track the progress of each task and update its status.
- Edit or Delete: Modify or remove tasks at any time.
- Calendar View: See all tasks in a calendar for better organization.

## Technologies Used
- Frontend: React
- Backend: Node.js, Express
- Database: MySQL
- Containerization: Docker, Docker Compose
- Other Tools: npm, dotenv

## Prerequisites
- Node.js >= 18
- npm >= 9
- Docker
- .env

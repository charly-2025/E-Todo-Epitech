# E-Todo

> Built at **Epitech Rennes** · B-WEB-101 · Web · November 2025

## Overview

A complete to-do list application: a Node.js/Express REST API backed by MySQL, and a React interface to create, track and organize tasks, with a calendar view of upcoming deadlines.

## Features

- Node.js / Express REST API with authentication
- MySQL database (schema in `e-todo.sql`)
- React interface: create, edit, update status and delete tasks
- Calendar view of deadlines
- One-command setup with Docker Compose

## Tech stack

`React` · `Node.js` · `Express` · `MySQL` · `Docker`

## E-Todo Project

E-Todo is a web application for managing your to-do tasks efficiently. You can create, update, and track your tasks, all in one place, with a calendar view to visualize deadlines.

### Features
- Create To-Dos: Add tasks with a title, description, and custom deadline.
- Update Status: Track the progress of each task and update its status.
- Edit or Delete: Modify or remove tasks at any time.
- Calendar View: See all tasks in a calendar for better organization.

### Technologies Used
- Frontend: React
- Backend: Node.js, Express
- Database: MySQL
- Containerization: Docker, Docker Compose
- Other Tools: npm, dotenv

### Prerequisites
- Node.js >= 18
- npm >= 9
- Docker
- .env
